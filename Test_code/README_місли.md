# Объяснение программы

Программа разделена на три файла. Это позволяет отдельно хранить описание
функций, их реализацию и основной сценарий работы.

## 1. `Test_1.h` — описание функций

Файл `Test_1.h` содержит объявления функций:

```c
int input_number_of_values(void);
double *input_from_console(double *data, int count);
void print(const double *data, int count);
double get_sum(const double *data, int count);
void assert_equal(double expected, double actual, const char *message);
```

Объявление сообщает компилятору, что функция существует, какие параметры она
принимает и какой тип данных возвращает. Реализация функций находится в
файле `Test.c`.

В начале подключаются стандартные библиотеки:

```c
#include <stdio.h>
#include <stdlib.h>
```

`stdio.h` нужен для `printf`, `scanf`, `fprintf` и `fflush`.
`stdlib.h` нужен для `calloc`, `free` и `NULL`.

Конструкции `#ifndef`, `#define` и `#endif` не позволяют подключить один и
тот же заголовочный файл несколько раз.

## 2. `Test.c` — реализация функций

В начале файла подключается заголовок:

```c
#include "Test_1.h"
```

После этого в файле можно реализовать функции, объявленные в `Test_1.h`.

### Функция `input_number_of_values`

```c
int input_number_of_values()
```

Функция просит пользователя ввести количество элементов массива. Например,
если пользователь вводит `3`, функция возвращает число `3`.

### Функция `input_from_console`

```c
double *input_from_console(double *data, int count)
```

Функция получает указатель на массив и количество элементов.

В `main` указатель сначала равен `NULL`, поэтому функция выделяет динамическую
память:

```c
data = calloc(count, sizeof(double));
```

При `count`, равном `3`, выделяется память для трёх переменных типа `double`.
Затем программа считывает значения в цикле:

```c
for (int i = 0; i < count; i++) {
    scanf("%lf", &data[i]);
}
```

Если пользователь указал `3`, нужно ввести ровно три числа, например:

```text
1.5 2.5 4
```

После заполнения функция возвращает адрес массива.

### Функция `print`

```c
void print(const double *data, int count)
```

Функция выводит элементы массива в цикле. Ключевое слово `const` означает, что
функция может читать массив, но не изменяет его.

### Функция `get_sum`

```c
double get_sum(const double *data, int count)
```

Функция складывает все элементы массива:

```c
double sum = 0.0;

for (int i = 0; i < count; i++) {
    sum += data[i];
}
```

Для массива `1.5 2.5 4` результат будет равен `8`.

### Функция `assert_equal`

Функция сравнивает ожидаемое и фактическое значения и выводит сообщение
`PASS` или `FAIL`. В текущем `main` эта функция не вызывается, но она
подготовлена для тестирования.

## 3. `Test_1.c` — основная программа

В этом файле находится функция `main`. Именно с неё начинается выполнение
программы.

### Шаг 1. Создание указателя

```c
double *v = NULL;
```

`v` — указатель на динамический массив. Изначально массив ещё не создан,
поэтому указатель равен `NULL`.

### Шаг 2. Ввод количества элементов

```c
int count = input_number_of_values();
```

Вызывается функция из `Test.c`. Введённое количество сохраняется в переменной
`count`.

### Шаг 3. Создание и заполнение массива

```c
v = input_from_console(v, count);
```

Функция из `Test.c` выделяет память, считывает значения и возвращает адрес
массива. Этот адрес сохраняется в `v`.

### Шаг 4. Проверка ошибки

```c
if (v == NULL) return 1;
```

Если память не удалось выделить или пользователь ввёл неправильные данные,
функция возвращает `NULL`, а программа завершается с кодом ошибки `1`.

### Шаг 5. Вывод массива

```c
print(v, count);
```

Вызывается функция `print` из `Test.c`, которая выводит все элементы массива.

### Шаг 6. Подсчёт суммы

```c
printf("Sum: %g\n", get_sum(v, count));
```

Сначала вызывается `get_sum`, затем полученный результат выводится на экран.

### Шаг 7. Освобождение памяти

```c
free(v);
```

Память, выделенная функцией `calloc`, освобождается функцией `free`. Это
необходимо делать после окончания работы с массивом.

## Как файлы работают вместе

Связь файлов выглядит так:

```text
Test_1.c  -> содержит main и запускает программу
Test_1.h  -> содержит объявления функций
Test.c    -> содержит реализации функций
```

Заголовок подключается в оба `.c` файла:

```c
#include "Test_1.h"
```

Для сборки нужно компилировать оба файла с исходным кодом:

```powershell
gcc Test.c Test_1.c -o lab5.exe
```

Файл `Test_1.h` отдельно компилировать не нужно.

## Пример работы

Пользователь должен сначала ввести количество элементов, а потом ровно столько
значений:

```text
Enter the number of values: 3
Enter an array of 3 values: 1.5 2.5 4
1.5 2.5 4
Sum: 8
```

Если ввести `5` как количество элементов, программа будет ждать пять чисел.
