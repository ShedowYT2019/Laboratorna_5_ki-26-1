# Лабораторна робота: вектори та матриці

Проєкт складається з трьох вихідних файлів:

```text
mylib.h       оголошення функцій
mylib.c       реалізація функцій
TestMyLib.c   main, введення даних і тестування
```

## Компіляція

Відкрийте термінал у папці `Lab_code` і виконайте:

```powershell
gcc -Wall -Wextra -std=c11 mylib.c TestMyLib.c -o TestMyLib.exe
```

Після компіляції запустіть програму:

```powershell
.\TestMyLib.exe
```

## Як працює програма

У файлі `TestMyLib.c` оголошено два покажчики:

```c
double *v;   // динамічний вектор
double **m;  // динамічна матриця
```

Покажчик `v` зберігає адресу динамічного вектора. Покажчик `m` зберігає
адресу масиву покажчиків на рядки матриці.

Спочатку програма отримує розмір вектора. Потім функція
`input_vector_from_console` з файлу `mylib.c` виділяє пам'ять за допомогою
`calloc` і заповнює вектор числами, введеними з консолі.

Матриця зберігається як масив покажчиків на окремі рядки. Спочатку
виділяється пам'ять під масив покажчиків, а потім окремо виділяється пам'ять
під кожен рядок:

```text
m -> рядок 0 -> значення
  -> рядок 1 -> значення
```

Тому матрицю потрібно звільняти у два етапи: спочатку звільнити кожен рядок,
а потім сам масив покажчиків. Це виконує функція `free_matrix` у файлі
`TestMyLib.c`.

## Призначення файлів

### `mylib.h`

У цьому файлі оголошено всі функції бібліотеки. Оголошення повідомляє
компілятору назву функції, її параметри та тип результату.

### `mylib.c`

У цьому файлі написано реалізацію функцій:

- пошук мінімального значення;
- пошук максимального значення;
- обчислення середнього значення;
- отримання всієї статистики;
- введення вектора та матриці;
- виведення вектора та матриці.

### `TestMyLib.c`

У цьому файлі знаходиться функція `main`. Вона:

1. запитує розмір вектора;
2. виділяє пам'ять і вводить вектор;
3. запитує кількість рядків і стовпців матриці;
4. виділяє пам'ять і вводить матрицю;
5. виводить вектор і матрицю;
6. обчислює мінімум, максимум і середнє значення;
7. звільняє всю виділену пам'ять.

## Функції статистики

Для вектора та матриці створено такі групи функцій:

- `get_min_...` шукає мінімальне значення;
- `get_max_...` шукає максимальне значення;
- `get_avg_...` додає всі значення та ділить суму на їх кількість;
- `get_stat_...` викликає три попередні функції та заповнює змінні
  `min`, `max` і `avg`.

Наприклад:

```c
get_stat_from_vector(v, vector_count, &min, &max, &avg);
```

Символ `&` перед змінною передає її адресу. Завдяки цьому функція може
записати результати безпосередньо у змінні `min`, `max` і `avg` з `main`.

## Динамічна пам'ять

Пам'ять виділяється за допомогою `calloc`:

```c
data = calloc(count, sizeof(double));
```

Після завершення роботи її потрібно звільнити:

```c
free(data);
```

Для матриці потрібно звільнити спочатку всі рядки, а потім саму матрицю:

```c
for (int i = 0; i < rows; i++) {
    free(data[i]);
}
free(data);
```

Якщо не звільняти пам'ять, виникає витік пам'яті.

## Макрос `USE_TEST`

У файлі `TestMyLib.c` є блок:

```c
#ifdef USE_TEST
    run_tests();
    return 0;
#endif
```

Якщо макрос визначено, програма запускає підготовлені тести і не запитує
дані з консолі.

Збірка програми з тестами:

```powershell
gcc -Wall -Wextra -std=c11 -DUSE_TEST mylib.c TestMyLib.c -o TestMyLib_tests.exe
```

Запуск тестів:

```powershell
.\TestMyLib_tests.exe
```

Параметр `-DUSE_TEST` повідомляє компілятору, що потрібно визначити макрос
`USE_TEST`.

## Як змінити тестові дані

Тестові дані знаходяться у функції `run_tests` у файлі `TestMyLib.c`.
Наприклад, вектор задається так:

```c
double vector[] = {-2.0, 4.0, 6.0};
```

Еталонне мінімальне значення перевіряється так:

```c
almost_equal(get_min_from_vector(vector_ptr, 3), -2.0)
```

Якщо змінити значення у масиві, потрібно також змінити очікуваний результат
у відповідній перевірці.

## Приклад ручного запуску

```text
Введіть розмір вектора: 3
Введіть 3 значення вектора: 1 5 -2
Введіть кількість рядків і стовпців матриці: 2 2
Введіть 4 значення матриці: 4 8 0 -1

Вектор: 1 5 -2
Вектор: min=-2, max=5, avg=1.33333

Матриця:
4 8
0 -1
Матриця: min=-1, max=8, avg=2.75
```

Спочатку потрібно ввести кількість елементів, а потім рівно стільки значень,
скільки було вказано. Для матриці з `rows=2` і `cols=3` потрібно ввести
`6` чисел.
